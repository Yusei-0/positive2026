Frases en Inglés 🇬🇧
/phrases - Todas las frases en inglés
/phrases?category_id=1 - Filtradas por categoría (ejemplo: ID 1)
/phrases?author_id=1 - Filtradas por autor (ejemplo: ID 1)
/phrases?category_id=1&author_id=1 - Filtradas por ambos
/phrase - Una frase aleatoria en inglés
/phrase?category_id=1 - Aleatoria con filtro por categoría
/phrase?author_id=1 - Aleatoria con filtro por autor
/phrase/1 - Frase específica por ID (ejemplo: ID 1)
